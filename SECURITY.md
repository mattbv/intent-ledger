# Security

Intent Ledger makes no network requests, spawns no processes, reads and writes no files and calls no model (see "Privacy and reach" in the README). Text the agent logs can come from untrusted content, so it is stripped of control characters and escaped before it reaches the pane or SVG.

If you find a vulnerability, please report it privately through [GitHub security advisories](https://github.com/mattbv/intent-ledger/security/advisories/new) rather than a public issue.
